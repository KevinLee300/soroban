# 小小珠算

給家裡小朋友用的珠算學習網頁：看動畫學口訣，再自己撥算盤練習。

目前有：
- **珠算**：認識算盤、直接加減、五的好朋友、十的好朋友，附錢幣對照動畫和算盤題庫。
- **九九乘法**（給小二）：乘法表、練習、限時 60 秒挑戰、弱點加強。
- **幼兒數學**：數甜甜圈、比大小、加減、平分、形狀、長短、規律、錢幣、看時鐘、動動腦，共 18 個小遊戲。

## 數學練習單

在「幼兒數學」最上方進入「數學練習單」：
- **單一題型**：接著填、比大小、分一分、加一加、減一減、找數字；整張六區練同一種題目。
- **混合題**：六種題目各一區，保留原本的 13 格。
- 每種都有簡單／普通／挑戰，星星依家人、題型與難度分開記。全部填完一次交卷，也可以列印。

## 上線給家人用（GitHub Pages）
1. 這個 repo 設成 **Public**（免費帳號的 GitHub Pages 只能用在公開 repo；程式裡沒有任何個資或密碼）。
2. GitHub repo → **Settings → Pages** → Source 選 **Deploy from a branch**，Branch 選 `main`、資料夾 `/ (root)`，按 Save。
3. 等 1–2 分鐘，網址會是 `https://<你的帳號>.github.io/<repo 名稱>/`。
4. 把網址貼到 LINE 家庭群組就好。

## 加到手機主畫面（像 App 一樣打開）
- 按網站下方的「加入主畫面」。支援安裝提示的 Chrome／Edge 會顯示安裝確認；其他情況會顯示操作步驟。
- **iPhone／iPad**：用 Safari 開啟，按「分享」→「加入主畫面」→「加入」。若有「作為網頁 App 打開」，請開啟。
- **LINE 等 App 內瀏覽器**：先從 App 選單用外部瀏覽器開啟，再加入主畫面。
- **分享安裝說明**：按「看安裝步驟」→「複製連結」，或在網站網址最後加上 `#install`。開連結會顯示步驟，仍需要使用者確認安裝。
- 加好之後沒有網路也能練習；有網路時每次打開都會自動拿到最新版。

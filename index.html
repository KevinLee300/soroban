    朗讀的聲音

    聲音太像機器人？這樣可以換成比較自然的台灣女聲（都免費）
    • Windows 電腦：改用 Microsoft Edge 瀏覽器打開網站，上面的選單會出現「曉臻（自然）」和「曉雨（自然）」，是最自然的台灣女聲。
    • iPhone／iPad：設定 → 輔助使用 → 朗讀內容（語音內容）→ 聲音 → 中文 → 國語（台灣）→ 下載「美佳（高品質）」。
    • Mac：系統設定 → 輔助使用 → 語音內容 → 系統聲音 → 管理聲音 → 中文（台灣）→ 下載「美佳（高品質）」。
    • Android：到 Play 商店更新「Google 語音服務」，再到 設定 → 系統 → 語言與輸入 → 文字轉語音 → 安裝語音資料 → 中文（台灣）。

    裝好之後回到這一頁重新整理，新的聲音就會出現在選單裡。聲音是存在每一台裝置裡的，手機和電腦要各自設定。
